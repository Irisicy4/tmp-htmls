Agentic Judge — presentation decks

Iterations of the grounded-judging design.

Decks

  • v3 · Plain-language deck (latest)
    Streamlined for a non-engineering audience. The same architecture, written as continuous prose without code snippets or version labels.
  • v2 · Technical deck with system prompts
    Shows the actual judge prompts, predicate lists, and follow-up loop rules. Page 2 has the true-positive / false-negative / false-positive analysis.
  • v1 · Original three-judge design
    Single-pass version with structural checks, substring-match source checking, and LLM rubric scoring.

Data

  • Zero-shot SFT Trajectories — 30 samples + stats
    GPT-5.4-mini exploring ScanNet scenes to answer ScanQA training questions through the thinking-in-space render pipeline. Bank-wide summary statistics (rounds, <think> blocks, action mix, scoring funnel, explored-to-find rate) plus 30 random GOOD trajectories with frame strips, per-turn reasoning + action, and answer vs. ground truth.
  • Start-Not-Visible Exploration Trajectories
    The exploration variant: every trajectory starts from a pose where the target object is off-frame, so the model must move to find it before answering (100% explored-to-find). Step statistics vs. the visible-start bank (hidden starts add ~40% more move-steps) plus 30 examples, multi-step first, with the hidden start frame highlighted.
  • 3D Data Survey
    3D datasets for scene/object understanding and 3D–language modeling, partitioned into training-QA / benchmarks / pure-scene (non-QA), with volume, mesh availability, key formats, links, and download method.
  • Reasoning-Retrieval Sample QC Review
    Manual QC of the first 600 of a 1,000-sample reasoning-retrieval draw: pie chart of pass/fail categories, then each of the 139 flagged samples grouped by failure type with query/target thumbnails, instruction, and rationale.
  • Results.parquet QC Review
    Manual tagging of a 100-sample review (0-indexed) of ba8ab380-results.parquet: pie chart over 8 good and 45 issues across 5 failure types (non-identifiable, size mismatch, text shortcut, complete mismatch, same combo), each with query/target thumbnails, instruction, and rationale.
  • Instruct Subset QC Review
    Manual tagging of the first 100 samples of the instruct_subset500 upload: pie chart over 34 good and 29 issues across 5 failure types (non-identifiable, spec mismatch, text shortcut, complete mismatch, repetitive pair), each with query/target thumbnails + sha256, instruction, and rationale.
