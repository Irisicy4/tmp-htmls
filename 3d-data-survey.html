3D Data Survey

3D datasets for scene/object understanding and 3D–language modeling, partitioned by primary use. Volume = cleaned/usable item counts. QA & grounding sets reuse a base scene corpus, marked via X. 3D loc = is the object the question/description is about annotated with a 3D location (instance id / box)? Scene table breaks the mesh down by source, appearance and posed-RGB availability — which together determine what renderer can consume it (vertex-color → raycast only; UV/PBR textures → rasterizer or path tracer; posed RGB → NeRF/3DGS trainable).

Pure 3D data · scene & object (non-QA)

Raw geometry corpora — the base 3D the sets above annotate. obj = object-level, scn = scene-level. The three mesh columns + posed-RGB column determine the usable renderer: vertex-color mesh → raycast/rasterize flat colors only; UV/PBR textured → full rasterizer or path tracer; posed real RGB → per-scene NeRF/3DGS trainable (photoreal novel views).
